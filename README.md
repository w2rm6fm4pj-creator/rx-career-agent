# RX Career Agent

Your AI assistant's guide to understanding your experience, finding suitable jobs, creating tailored resumes in Reactive Resume, and preparing applications for your approval.

**New here? Read [Start here: your personal career assistant](START-HERE.md).** It walks through Codex or Claude setup, creating your own RX account, connecting it, and your first application. No coding or Git knowledge required.

- [Help someone get started](HELP-SOMEONE-START.md) — a guide for the person sharing it.

## How it works

You install these instructions in a capable AI assistant. The assistant interviews you, builds your search criteria, verifies vacancies, and tailors copies of your resume and cover letter. You approve compensation and the completed application before submission. Your original resume is preserved.

Each person uses their own accounts. The assistant helps create and verify an RX account, then guides a supported sign-in connection or private API-key setup. Never put keys or personal application records in this repository.

## What is included

The ZIP contains the skill and its workflow references. It is not a hosted service or an executable installer. Research, PDF checks, RX editing and browser actions depend on the tools available in your app. RX access does not grant access to employer accounts or email.

The skill uses a format supported by Codex and Claude. Structure and archive integrity have been checked; the complete workflow still needs a fresh-user test, including a Claude test. No ATS outcome, interview or offer is guaranteed.

This repository is private. Recipients need access, or you can share the package and guide directly.
