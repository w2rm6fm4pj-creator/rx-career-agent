# Help someone get started

For this pilot, deployment means giving a person the skill and helping them connect their own accounts. There is no server to launch and no need for them to clone a repository.

## Before the first session

1. Send the person the START-HERE guide and rx-career-agent.zip, or grant them access to this private repository and share its link. A private link alone will not work for someone without access.
2. Ask them to have their current resume ready and know how to sign into their chosen AI app. They can create their own RX account during setup.
3. Start with their existing assistant if it supports skills and the necessary tools. Confirm availability before recommending a subscription or purchase.
4. Let them enter passwords, verification codes and credentials themselves. Do not collect their API key or lend them your account.

## Walk through one successful cycle

Help install the skill. Ask the assistant to check capabilities. Follow RX registration and connection in START-HERE, verify account identity, then create one draft. Ask the person to review the resume PDF and search brief. Prepare one application and verify the salary and final-submission checkpoints work before expanding the search.

Keep a short, nonpersonal setup note: app used, skill installation succeeded, RX connection type, PDF checks available, browser actions available, and unresolved steps. Do not describe an untested step as working.

## Message you can send

> I've put together a career-assistant workflow you can use with your own AI account. It helps you clarify your experience, find suitable opportunities and prepare tailored applications. Start with the attached guide and skill ZIP. The guide includes creating your own RX Resume account and connecting it. You keep control of salary decisions and final submissions. Let's test the first setup together; you don't need to know how to code.

Share updates by sending the new ZIP. Have the assistant replace only its skill instructions, preserving the recipient's separate private career records and credentials. Keep each person's resume, search history and keys out of the distribution repository.
